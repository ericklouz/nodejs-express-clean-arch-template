# About The Project
The purpose of this project is to provide a base template for the development of robust and scalable APIs. This template follows SOLID principles and is structured according to clean architecture principles, making it easy to maintain and extend the code over time.

# Getting Started
To get started with this project, follow the instructions below to set up your development environment. Make sure you have Node.js and npm installed on your machine. This section will guide you through the process of cloning the repository, installing dependencies, and running the development server.

## Prerequisites
- Node.js v20.16.0 or higher
- npm v6.x or higher

## Installation
**Step 1:** Clone the repository:
```bash
git clone https://github.com/tuusuario/clean-arch-template.git
```

**Step 2:** Access the project directory:
```bash
cd clean-arch-template
```

**Step 3:** Install the dependencies:
```bash
npm install
```

## Environment Variables
To run this project, you will need to add the following environment variables to your .env.development file (for development).

# Usage
To start the development server:

```javascript
npm run dev
```

The server will be available at http://localhost:3000.
